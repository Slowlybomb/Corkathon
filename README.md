## Dashboard prototype

The fullscreen map dashboard prototype is in [dashboard/](dashboard/README.md), with a small, replaceable sample survey.

```sh
python3 -m http.server 5173 --directory dashboard
```

Open http://localhost:5173. No installation or build step is required. All observations and map positions are illustrative; no AI analysis or drone flight is performed.
